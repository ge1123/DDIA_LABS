# Experiments

Executable Labs live in `experiments/<lab-id>/`. Do not add a Lab implementation until its canonical page under [`wiki/labs/`](../wiki/labs/index.md) defines the question, falsifiable hypothesis, variables, measurement, safety boundary, reproduction command, and cleanup.

Use the proposed [experiment architecture](../wiki/architecture/experiment-architecture.md) as the starting convention. A Lab may use fewer directories when they add no value.
