# Templates

Start new canonical pages from the closest template, then remove placeholder sections that genuinely do not apply.

| Template | Use for |
| --- | --- |
| [Concept](concept.md) | A source-grounded explanation and its trade-offs |
| [Lab](lab.md) | A falsifiable, reproducible experiment |
| [Decision](decision.md) | An accepted repository or experiment choice |
| [QA](qa.md) | A repeatable evidence or acceptance rule |
| [Problem](problem.md) | A diagnosed experiment or measurement failure |

When adding a new template type, update this index and [the Wiki maintenance guide](../AGENTS.md) if its evidence or status rules differ.
